# ZANNY Birthday 🎀

Site de homenagem de aniversário em HTML, CSS e JavaScript.

## Como usar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Clique em **⚙️ Painel**.
4. Senha inicial: **zanny2026**
5. Adicione a mensagem, assinatura, data e fotos.
6. Salve.

As fotos e configurações são armazenadas no `localStorage` do navegador.

## Publicar
Pode colocar a pasta em serviços de hospedagem estática como GitHub Pages ou Vercel.

## Importante sobre o painel
Este projeto é uma versão estática. A senha do painel fica no JavaScript, portanto não é uma proteção real para dados secretos. Para um painel administrativo seguro e fotos compartilhadas entre vários celulares/computadores, a próxima versão deve usar Firebase Authentication + Firestore + Storage.
